# DroyalSuites — Premium React Build

A high-end responsive React/Vite marketing site for DroyalSuites.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Design direction

- Bright cream / baby-yellow / banana-yellow gradient environment across the whole app.
- Yellow CTA buttons with restrained black contrast.
- Fresh property photography from Pexels (not crops from the banner).
- Custom property-owner dashboard UI built in React/CSS.
- Responsive layouts for desktop, tablet and mobile.
- Floating WhatsApp contact: 0810 955 8527.
